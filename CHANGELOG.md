# Changelog

## 0.1.1 — 2026-10-13
- Every skill ends its reply with one **Next:** line: the words the student can type for the next step, with the skill in brackets (rest instead, when the student sounds under strain). The line is in the shared Care block of all six skills.
- study-cards: Next is a quiz on the same material tomorrow, or a revision plan when an exam date was given.
- study-quiz: a result line in one block to keep and paste back; Next is cards from the missed questions.
- study-grade: a flashcard for each missing or wrong point, in an Anki block; Next is a quiz once the passage is reread.
- study-explain: after the check question is answered, two to four flashcards on the concept; Next is a quiz on the section.
- study-plan: the table gains `type this` (the words for that day) and `done` (a box to tick); Next is today's row. The description no longer reads as "not without a date" (the skill asks for the date).
- study-exam: a result line in one block; Next is cards for the weakest section, or a plan when an exam date was given.
- README: a "Try it first" line on the first screen.
- Evals: every case gains a grader that the reply ends with a Next line (in the student's language for the Hebrew and Arabic cases).

## 0.1.0 — 2026-10-06
- First release: study-cards, study-quiz, study-grade, study-explain, study-plan, study-exam.
